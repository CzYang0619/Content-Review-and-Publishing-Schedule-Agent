# AI 使用说明与个人贡献边界

本项目由候选人选择题目并授权 Codex AI 辅助完成实现。AI 辅助范围：需求拆解、方案设计、Python 代码、测试用例、合成资料、文档初稿、运行验证及错误修复。AI 读取官方接口文档并通过工具运行实际测试；未伪造模型输出。

候选人当前已确认的贡献：提供考试规范、选择第 1 题、确定完整交付目标。**尚未观察到候选人自行修改代码、手动复验或解释方案的记录，因此不将这些写为已完成个人贡献。** 提交前应亲自运行、阅读并补充实际个人修改与验证；不能把 AI 完成的工作描述为个人独立开发。

工具：Codex AI 编码辅助、Python 3.12.14、SQLite、Git；未使用 Agent 框架。业务数据均为合成数据。运行时真实模型默认 gpt-4.1-mini，可配置；目前 HTTP 401，未获得成功真实模型运行记录。离线决策模拟器只是流程验证。

个人验证记录请按实际情况追加：日期、运行命令、观察结果、修改文件、修改原因、是否通过。不得为了填满文档虚构个人验证。

项目没有读取或提交真实隐私素材。API 密钥只从环境获取，不进入代码或 Trace。HTTP 错误仅记录状态码，不记录认证头或响应正文。
