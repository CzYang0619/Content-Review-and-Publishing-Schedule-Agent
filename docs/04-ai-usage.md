# AI 使用说明与个人贡献边界

本项目由候选人选择题目并授权 Codex AI 辅助完成实现。AI 辅助范围：需求拆解、方案设计、Python 代码、测试用例、合成资料、文档初稿、运行验证及错误修复。AI 读取官方接口文档并通过工具运行实际测试；未伪造模型输出。

候选人当前已确认的贡献：提供考试规范、选择第 1 题、确定完整交付目标、提供目标 GitHub 仓库并完成账号授权、参与免费模型平台选择并提供智谱接入凭据。个人独立修改代码及复验尚未记录，提交前按实际情况补充；不将 AI 完成的工作描述为个人独立开发。

工具：Codex AI 编码辅助、Python 3.12.14、SQLite、Git；未使用 Agent 框架。业务数据均为合成数据。最终真实验收采用智谱 glm-4-flash-250414，10 组案例通过；此前测试过 glm-4.7-flash（较慢、过载及参数误选）和 OpenAI 接口（401、额度耗尽），失败记录如实保留。通用适配器仍支持配置其他兼容模型。离线决策模拟器只是流程验证。

个人验证记录请按实际情况追加：日期、运行命令、观察结果、修改文件、修改原因、是否通过。不得为了填满文档虚构个人验证。

项目没有读取或提交真实隐私素材。API 密钥由本机隐藏输入或进程环境传入，不进入代码或 Trace。HTTP 错误仅记录状态码及白名单业务码，不记录认证头或原始响应正文。
